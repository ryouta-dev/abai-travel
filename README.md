# ABAI TRAVEL

Интерактивный прототип смарт-гида по Абайской области. В нём восемь экранов, интерфейс на казахском и русском, четыре маршрута и аудиогид на трёх языках.

Открыть прототип: https://ryouta-dev.github.io/abai-travel/

Для локального просмотра запустите `python -m http.server 8000` из корня и откройте http://localhost:8000.

Карта схематическая. Оплата имитируется. Прогресс, настройки и отзывы хранятся в браузере. Поддержка в WhatsApp показана как планируемая функция.

Фотографии взяты из Wikimedia Commons, уменьшены и сохранены в WebP. Авторы, исходники и лицензии доступны в меню «Авторы фотографий» на сайте. Озвучка синтезирована.
